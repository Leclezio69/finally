## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frontend → Backend API | WatchlistContext calls POST /api/watchlist and DELETE /api/watchlist/{ticker}; ticker input crosses here |
| SSE stream → Frontend | price_update events parsed with JSON.parse in PriceContext; malformed data skipped silently (existing) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | addTicker() — ticker string sent to POST /api/watchlist | mitigate | Uppercase normalize in addTicker() before API call; backend validates and rejects invalid tickers via HTTP 400/409 |
| T-02-02 | Information Disclosure | priceHistory ring buffer exposed via context | accept | Data is market prices from public SSE stream; no PII, no sensitive values; single-user app with no auth boundary |
| T-02-03 | Denial of Service | priceHistoryRef unbounded growth risk | mitigate | slice(-100) cap per D-03 enforced in accumulation effect; 100 entries × ~8 bytes per float × N tickers is bounded and acceptable |
| T-02-SC | Tampering | npm install lightweight-charts@5.2.0 | mitigate | Package is published by TradingView (verified in RESEARCH.md Package Legitimacy section); pinned to exact version 5.2.0 in install command |
</threat_model>
