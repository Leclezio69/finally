## Phase Goal

**As a** trader, **I want to** see a live price chart for the selected ticker, **so that** I can read price trends at a glance and switch between tickers by clicking.

<objective>
Build the MainChart component using lightweight-charts v5. The chart auto-selects the first ticker on load, renders its accumulated price history, and receives live updates via series.update() on each SSE tick. Switching tickers calls series.setData() with the new ticker's history buffer. Mount MainChart in page.tsx replacing the chart placeholder.

Purpose: Completes the Phase 2 vertical slice — user can now click any ticker in the watchlist and see its live chart in the main area.

Output: MainChart.tsx + updated page.tsx. Observable: clicking TSLA in the watchlist immediately updates the chart to show TSLA prices.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSE price data → Canvas | price and timestamp from PriceUpdate feed the lightweight-charts series; canvas rendering is sandboxed by the browser |
| priceHistory buffer → chart.setData() | number[] from WatchlistContext is converted to UTCTimestamp series without any user-supplied string interpolation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Injection (XSS) | MainChart renders selectedTicker and price in the header div | accept | React JSX escapes string values by default; no dangerouslySetInnerHTML used; selectedTicker is a backend-validated ticker symbol |
| T-02-09 | Denial of Service | ResizeObserver firing on every pixel resize, triggering chart.resize() | accept | ResizeObserver batches callbacks per browser frame; chart.resize() is a cheap canvas operation; no debouncing needed for this use case |
| T-02-10 | Tampering | synthesized timestamps for history buffer (spaced 500ms apart) are approximate | accept | History is visual only — no financial calculations depend on exact timestamps; approximate times are clearly documented in code comments |
| T-02-11 | Denial of Service | setData() called with large history arrays on ticker switch | accept | History is capped at 100 points by WatchlistContext ring buffer (D-03); 100-point setData is O(n) with negligible cost |
| T-02-SC | Tampering | No new npm packages installed in this plan | accept | lightweight-charts already installed in plan 02-01; no additional registry access |
</threat_model>
