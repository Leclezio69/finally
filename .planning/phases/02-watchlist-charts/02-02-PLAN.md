## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Injection (XSS) | WatchlistRow renders ticker symbol in DOM | accept | React escapes string values in JSX by default — no dangerouslySetInnerHTML used anywhere in this component; ticker is a backend-returned string that was already uppercased and validated by the API |
| T-02-05 | Injection (XSS) | WatchlistPanel renders error messages in DOM | accept | Error strings are static literals set by frontend code (`'Already watching ${input}'`, `'Failed to add ticker. Try again.'`), not raw API response text; no HTML injection possible |
| T-02-06 | Tampering | Add-ticker input: arbitrary ticker symbols submitted | mitigate | `toUpperCase()` normalization applied before API call; backend validates ticker format and returns 400 for invalid; button disabled during in-flight request to prevent double-submit |
| T-02-07 | Denial of Service | Rapid add-ticker clicks generating many API requests | mitigate | `loading` state disables button and input during in-flight call; only one concurrent addTicker request possible per UI session |
| T-02-SC | Tampering | No new npm packages installed in this plan | accept | All component code is custom-written; no new dependencies; lightweight-charts installed in plan 02-01 |
</threat_model>
