## Component Inventory

### WatchlistPanel (gridArea: 'watch')

Replaces `<PlaceholderPanel label="WATCHLIST">` in `page.tsx`.

**Structure (top to bottom):**
1. Panel header: "WATCHLIST" label, 11px semibold, `text-text-muted`, letter-spacing `0.15em`, padding 8px 8px
2. Ticker list: scrollable container (`overflow-y: auto`), each row is a `WatchlistRow`
3. Divider: 1px solid `border-border`, full width
4. Add-ticker area: always visible, pinned to bottom. Contains text input + "Add" button in a row.

**Panel header dimensions:**
- Height: 32px
- Background: `bg-bg-panel` (same as panel)
- Border-bottom: 1px solid `border-border`

**Add-ticker area dimensions:**
- Height: 40px
- Padding: 4px 8px
- Input: flex-grow, height 28px, background `bg-bg-base`, border 1px solid `border-border`, color `text-text-primary`, placeholder "Ticker...", font-size 13px, padding-left 8px
- Button: width 48px, height 28px, background `bg-accent-blue`, color `#ffffff`, font-size 11px, font-weight 600, text "ADD", no border-radius (terminal aesthetic per VIS-04)

### WatchlistRow

**Layout:** Single row, horizontal flex, align-items center, height 36px, padding 0 8px.

| Column | Width | Content | Alignment |
|--------|-------|---------|-----------|
| Ticker symbol | 52px | e.g. "AAPL" | Left, semibold 13px, `text-text-primary` |
| Price | 64px | e.g. "192.45" | Right, regular 13px, `text-text-primary` |
| Change % | 52px | e.g. "+1.23%" | Right, regular 13px, green (#22c55e) or red (#ef4444) |
| Sparkline | 60px | SVG polyline | Right |
| Remove button | 16px | "x" character | Right, visible on hover only, `text-text-muted`, cursor pointer |

**Interaction states:**
- Default: background transparent
- Hover: background `bg-bg-surface` (`#161b22`), remove "x" becomes visible
- Selected: background `bg-bg-surface`, left border 2px solid `accent-blue` (`#209dd7`), padding-left reduced to 6px to compensate
- Price flash: apply `.flash-up` or `.flash-down` CSS class to the price cell on direction change, remove after 500ms via setTimeout

**Flash animation behavior:**
- On each SSE price update, compare `direction` field from `PriceUpdate`
- If `direction === 'up'`: add `.flash-up` class to the price cell
- If `direction === 'down'`: add `.flash-down` class to the price cell
- After 500ms, remove the class (use `setTimeout` + React ref or key trick)
- Flash applies to the price cell only, not the entire row

### Sparkline (inline SVG)

Per decisions D-01, D-02, D-03:

- Dimensions: 60px wide, 24px tall
- Element: `<svg>` with a single `<polyline>` element
- Data: array of up to 100 price points (ring buffer, `slice(-100)`)
- X axis: evenly distributed across 60px width (`index / (points.length - 1) * 60`)
- Y axis: scaled between min and max of the buffer, mapped to 2px...22px (2px padding top/bottom within 24px)
- Stroke color: `#22c55e` if current price >= first price in buffer, `#ef4444` if lower (per D-02)
- Stroke width: 1.5px
- Fill: none
- No axes, no labels, no borders, no background

### MainChart (gridArea: 'chart')

Replaces `<PlaceholderPanel label="CHART">` in `page.tsx`.

Per decisions D-04, D-05, D-06:

**Structure:**
1. Chart header bar: height 32px, background `bg-bg-base`, border-bottom 1px solid `border-border`, padding 0 16px. Shows selected ticker symbol (13px semibold) and latest price (13px regular, colored green/red based on direction).
2. Chart container: fills remaining height, lightweight-charts instance

**Chart configuration:**
- Library: lightweight-charts (TradingView), single instance
- Series type: Area series (filled area under the line provides depth without clutter, fits terminal aesthetic)
- Chart background: `#0d1117` (bg-base)
- Grid lines: horizontal only, color `#161b22` (subtle, barely visible)
- Crosshair: enabled, mode Magnet, line color `#30363d`
- Time axis: visible, text color `#8b949e`, border color `#30363d`
- Price axis: visible, text color `#8b949e`, border color `#30363d`
- Area series top color: `rgba(32, 157, 215, 0.4)` (accent-blue at 40% opacity)
- Area series bottom color: `rgba(32, 157, 215, 0.0)` (fade to transparent)
- Area series line color: `#209dd7` (accent-blue)
- Area series line width: 2
- Time values: use wall clock from SSE `timestamp` field, displayed as HH:MM:SS
- Resize: chart must call `chart.applyOptions({ width, height })` on container resize (use ResizeObserver)

**Data flow:**
- On each SSE tick for the selected ticker: call `series.update({ time: unixTimestamp, value: price })` (per D-06)
- When selected ticker changes: call `series.setData(historyBuffer)` to load the new ticker's accumulated history, then continue with `update()` calls
- History buffer: same 100-point ring buffer shared with sparklines (per D-05)

**Empty state (before first SSE tick arrives):**
- Show "Waiting for data..." centered in the chart area, 13px regular, `text-text-muted`

### WatchlistContext (provider)

Per decisions D-09 through D-12:

**Exports:**
- `WatchlistProvider` — wraps children in layout.tsx alongside PriceProvider
- `useWatchlist()` — returns `{ tickers, selectedTicker, setSelectedTicker, addTicker, removeTicker }`

**State:**
- `tickers: string[]` — ordered list of ticker symbols
- `selectedTicker: string | null` — currently selected ticker
- `priceHistory: Record<string, number[]>` — per-ticker ring buffer of up to 100 prices

**Behavior:**
- On mount: `GET /api/watchlist` to fetch initial ticker list. Auto-select first ticker (D-11).
- `addTicker(ticker)`: uppercase the input, `POST /api/watchlist { ticker }`, append to `tickers` state on success
- `removeTicker(ticker)`: `DELETE /api/watchlist/{ticker}`, remove from `tickers` state on success. If removed ticker was selected, auto-select the first remaining ticker.
- Price history: on each SSE `price_update` event, append to the ticker's buffer in `priceHistory`, cap at 100 entries via `slice(-100)` (D-03)

## Interaction Contract

### Watchlist Row Click
- Action: `setSelectedTicker(ticker)` via WatchlistContext
- Visual feedback: selected row gets `bg-bg-surface` background + 2px left accent-blue border
- Side effect: main chart switches to show the clicked ticker's price history

### Add Ticker
- Input auto-uppercases as user types (D-07 discretion note)
- Submit on Enter key or "ADD" button click
- Disable button and input while API call is in flight (prevent double-submit)
- On success: clear input, new ticker appears at bottom of watchlist, SSE begins streaming it
- On duplicate: show "Already watching {TICKER}" error text
- On API error: show "Failed to add ticker" error text

### Remove Ticker
- Hover watchlist row to reveal "x" button (D-08)
- Click "x": fires `DELETE /api/watchlist/{ticker}` immediately, no confirmation dialog
- On success: row disappears, if it was selected ticker, first remaining ticker becomes selected
- On API error: row remains, no error shown (silent failure acceptable for remove)

### Price Flash
- Triggered by SSE `price_update` event where `direction` is 'up' or 'down'
- Apply `.flash-up` or `.flash-down` class to the price cell element
- Remove class after 500ms
- If a new flash triggers before the previous one completes, restart the timer

### Chart Selection Change
- When `selectedTicker` changes, load that ticker's accumulated price history buffer into the chart via `series.setData()`
- Continue appending new ticks via `series.update()`
- Chart time scale auto-scrolls to show latest data (`timeScale().scrollToRealTime()`)
